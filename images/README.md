# Bilder

Sidan fungerar utan bilder – allt visas med SVG-platshållare. Lägg in riktiga
filer med exakt dessa namn så byts platshållarna ut automatiskt:

| Fil | Används till | Tips |
| --- | --- | --- |
| `logo.png` | Loggan i header och footer | Kvadratisk, rund logga, minst 200×200 px |
| `produkt.jpg` | Produktbilden överst på "Produkt & dofter" (visas i en cirkel) | Kvadratisk, minst 900×900 px |
| `favicon.svg` | Ikon i webbläsarfliken | Kan ersättas med egen |
